
# Educational Quality Analytics MVP

نسخة أولية بسيطة لتحليل استبانات تعليمية من ملفات Excel.

## الوظائف الحالية

- رفع ملفات Excel
- اختيار ورقة العمل
- اكتشاف الأعمدة الرقمية
- فحص القيم المفقودة
- كشف القيم خارج نطاق مقياس الاستجابة
- حساب الإحصاءات الوصفية
- حساب Cronbach's Alpha
- حساب تكرارات الإجابات
- تنزيل تقرير Excel

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. افتح PowerShell داخل مجلد المشروع.
3. أنشئ بيئة افتراضية:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

4. ثبّت المكتبات:

```powershell
pip install -r requirements.txt
```

5. شغّل المنصة:

```powershell
streamlit run app.py
```

سيظهر رابط محلي غالبًا:

```text
http://localhost:8501
```

## تنسيق ملف Excel

- الصف الأول: أسماء الأعمدة.
- كل صف بعده: استجابة مشارك واحد.
- إجابات الأسئلة تكون أرقامًا، مثل 1 إلى 5.
- يمكن وجود أعمدة نصية مثل الاسم أو الجنس، لكن لا تُختار ضمن أسئلة التحليل.
